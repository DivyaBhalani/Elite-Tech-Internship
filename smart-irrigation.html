Smart Irrigation System

This project uses Arduino and ESP32 to automate irrigation based on real-time soil moisture levels. It helps save water and increases farming efficiency using IoT technology.

The Smart Irrigation System uses soil moisture sensors to detect dryness and automatically triggers the motor to water the plants. It's ideal for remote agricultural use and saves up to 30–40% water. The system is programmable, low-power, and scalable for larger fields.
